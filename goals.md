# Мои цели на семестр по курсу DevOps

1. Освоить основные команды Git и научиться уверенно работать с ветками, коммитами и Pull Request.

2. Научиться работать с Docker и понимать основные принципы контейнеризации приложений.

3. Изучить основы CI/CD и научиться создавать простые автоматизированные процессы с помощью GitHub Actions.
