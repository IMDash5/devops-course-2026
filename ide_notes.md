# Удобство работы с Git в VS Code

3 удобные вещи в VS Code:

1. Удобно просматривать изменения в файлах через diff и видеть, какие строки были добавлены или изменены.
2. Можно быстро создавать коммиты и отправлять изменения в репозиторий через панель Source Control.
3. Удобно просматривать историю коммитов и отслеживать изменения в проекте.

Что удобнее делать в терминале:

Создавать и переключать ветки, а также выполнять сложные операции Git удобнее в терминале, поскольку там можно быстро использовать команды и лучше контролировать процесс.
